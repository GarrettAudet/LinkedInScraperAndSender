# Reporting a security issue

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/GarrettAudet/LinkedInScraperAndSender/security/advisories/new). Include the affected commit or version, the impact, and a minimal reproduction using test data.

Avoid public issues for unpatched vulnerabilities. Do not attach live credentials, private records, or other people's personal information. If a credential has been exposed, revoke or rotate it with its provider; deleting a file does not invalidate copies in Git history.
